# ADR 0008: 将来の推薦のためにeventを追加収集しない

- Status: Accepted
- Date: 2026-10-30

## 背景

将来は蓄積した履歴から次に送るBeatを推薦したい。推薦はMVPのout of scopeであり、MVP_SCOPEは将来のML利用だけを理由とする収集を禁じている。

## 決定

- MVPでは画面表示に必要なeventのみを収集する
- 収集したeventはappend-onlyで保持し、表示用summaryと分離する
- 推薦処理やBigQuery連携はMVPでは実装しない

## 検討した代替案

- **推薦用のdataを今から追加収集する**: 何が効くかはまだ不明で、匿名のArtistについて説明すべき収集範囲だけが増える
- **その都度判断する**: 基準がなく、収集範囲が広がりやすい

## 影響

- 「誰に何を送り、どう反応されたか」という推薦の基礎dataは自然に蓄積される
- privacy上の説明範囲を小さく保てる
- **弱点**: MVP後に必要と分かったdataは、過去にさかのぼって取得できない
